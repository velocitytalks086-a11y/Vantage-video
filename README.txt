VANTAGE MOTION STUDIO — BETA

A standalone, browser-based procedural motion graphics maker.

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome or desktop Safari recommended).
3. Choose a preset, edit title/subtitle and animation settings, then press Play.
4. Export Video records the animation in real time and downloads a WebM file.
5. Save Project downloads editable project settings as JSON; Import project JSON loads them again.

FEATURES
- Cinematic, Chrome title, Tech launch and Minimal presets
- Editable title, subtitle, text size/color, accent color and positioning
- Rise, zoom, type-on, glitch and fade reveal styles
- Procedural particle field, light sweep, glow, backgrounds and composition guides
- 16:9, 9:16 and 1:1 canvas formats
- Timeline scrubber and play/pause/restart
- Import image/logo into the preview
- Save/import project settings
- Local browser app; no account or cloud required

LIMITATIONS
- This is an early beta, not a full After Effects replacement.
- Export is WebM when supported by the browser; MP4 support varies. Recording happens in real time, so keep the tab open until export finishes.
- Imported image/logo is preview-only and is not embedded in the JSON project yet.
- Generated sound tone control is not implemented in this beta.
- Project JSON stores settings/layers, not imported image data.
